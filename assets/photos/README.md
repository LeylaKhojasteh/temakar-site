# عکس‌های خام

فایل‌های اصلی عکس‌ها را در همین پوشه بگذار. هر اسمی داشته باشند مهم نیست؛ بعد در چت
بگو هر فایل مربوط به کدام بخش است. من برش، اندازه و کیفیت را درست می‌کنم و بعد از
طریق پنل ثبت می‌کنم تا بعداً خودت هم بتوانی عوضشان کنی.

## جایگاه‌هایی که داریم

| جایگاه | نسبت |
| --- | --- |
| چهار خدمت (انتقال نیرو، تولید نیرو، نفت و گاز، مشاوره و آموزش) | افقی ۱۶:۱۰ |
| نوار «دربارهٔ ما» در صفحهٔ اصلی | افقی ۱۶:۹ |
| سرصفحهٔ معرفی شرکت | افقی ۱۶:۱۰ |
| سرصفحهٔ خدمات | افقی ۱۶:۱۰ |
| سرصفحهٔ تماس | افقی ۱۶:۱۰ |
| لوگو | مربع یا افقی، PNG با پس‌زمینهٔ شفاف |

## نکته

- فایل اصلی بهتر است؛ اگر از واتس‌اپ آمده، نسخهٔ «بدون فشرده‌سازی» را بگذار.
- حداقل عرض ۱۲۰۰ پیکسل برای سرصفحه‌ها.
- این پوشه در گیت ذخیره نمی‌شود؛ نسخهٔ اصلی عکس‌ها جای دیگری هم داشته باش.
