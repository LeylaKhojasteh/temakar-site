# PERFORMANCE.md — بودجه و اندازه‌گیری

اعداد این فایل روی محیط توسعهٔ محلی (ویندوز، Chrome، بدون شبیه‌سازی شبکه) اندازه‌گیری
شده‌اند. این اعداد برای مقایسهٔ قبل و بعد و کنترل بودجه است، نه دادهٔ میدانی کاربران واقعی.

---

## ۱. بودجهٔ پروژه

| منبع | بودجه | وضعیت فعلی |
| --- | --- | --- |
| HTML هر صفحه | کمتر از ۴۰ کیلوبایت | ۱۰ تا ۱۳ کیلوبایت |
| CSS | کمتر از ۳۵ کیلوبایت | ۲۸ کیلوبایت (مینیفای‌شده) |
| JS پایه | کمتر از ۱۰ کیلوبایت | ۴ کیلوبایت (`site.js`) |
| JS تعاملی | فقط در صفحه‌های لازم | HTMX ۵۰ کیلوبایت در خدمات و تماس، Quill فقط در ادمین |
| فونت | کمتر از ۲۰۰ کیلوبایت برای هر زبان | فارسی ۱۱۸ کیلوبایت، انگلیسی ۱۴۸ کیلوبایت (هر دو) |
| تصویر هر صفحه | کمتر از ۴۰۰ کیلوبایت | ۱۲۶ تا ۲۳۳ کیلوبایت |
| تصویر اصلی آپلودی | حداکثر ۲۰۰۰ پیکسل، کیفیت ۷۸ | بهینه‌سازی خودکار روی ذخیره |
| کارت | ۸۰۰×۵۰۰ | مشتق خودکار |
| بندانگشتی | ۱۶۰×۱۶۰ | مشتق خودکار |

## ۲. اندازه‌گیری قبل و بعد از بهینه‌سازی تصویر

| صفحه | قبل | بعد |
| --- | --- | --- |
| صفحهٔ اصلی فارسی | ۱۲۱۸ کیلوبایت | ۲۷۱ کیلوبایت |
| صفحهٔ اصلی انگلیسی | ۱۲۴۹ کیلوبایت | ۲۶۸ کیلوبایت |
| فهرست خدمات | ۱۱۷۷ کیلوبایت | ۳۶۵ کیلوبایت |
| تماس | ۲۰۲ کیلوبایت | ۳۴۱ کیلوبایت |

دلیل: پیش‌تر هر بندانگشتی ۱۶۰ پیکسلی، فایل ۱۶۰۰ پیکسلی (۱۲۰ تا ۲۰۰ کیلوبایت) را
دانلود می‌کرد. حالا هر تصویر هنگام ذخیره سه نسخه دارد و قالب نسخهٔ درست را می‌گیرد.
بازطراحی پوستری یک تصویر بزرگ سرصفحه و ترکیب چهار عکس منتخب اضافه کرد، پس عدد
صفحهٔ اصلی بالاتر رفت؛ این تصاویر زیر خط تاشو `loading=lazy` هستند.

## ۳. شاخص‌های آزمایشگاهی (محلی)

| صفحه | LCP | CLS |
| --- | --- | --- |
| `/fa/` | ۲۲۸ میلی‌ثانیه | ۰ |
| `/fa/our-services/` | ۱۷۶ میلی‌ثانیه | ۰ |
| `/fa/contact/` | ۲۰۸ میلی‌ثانیه | ۰ |

CLS صفر است چون همهٔ تصاویر `width` و `height` دارند، ارتفاع نوار تماس و نقشه رزرو
شده است و فونت با `font-display: swap` و preload بارگذاری می‌شود.

## ۴. تصمیم‌های کارایی

- فونت‌ها محلی و از پیش زیرمجموعه‌شده‌اند؛ برای هر زبان فقط فونت همان زبان preload می‌شود.
- HTMX فقط در صفحه‌های خدمات و تماس بارگذاری می‌شود و با `includeIndicatorStyles: false`
  هیچ استایل تزریقی ندارد.
- نقشهٔ گوگل `loading="lazy"` است و در صفحهٔ تماس، نقشهٔ فوتر تکرار نمی‌شود.
- تصاویر زیر خط تاشو `loading="lazy"` و `decoding="async"` دارند.
- ادمین و ویرایشگر متن غنی خارج از باندل عمومی هستند.
- انیمیشن‌ها فقط `opacity` و `transform` را تغییر می‌دهند و با `prefers-reduced-motion`
  خاموش می‌شوند.

## ۵. چه چیزی اندازه‌گیری نشده است

- دادهٔ میدانی کاربران (CrUX یا Web Vitals واقعی)
- شبکهٔ 3G/4G شبیه‌سازی‌شده
- Lighthouse رسمی

اگر این‌ها لازم شد، باید روی نسخهٔ پروداکشن و با throttling اندازه‌گیری شود و نتیجه
در همین فایل جایگزین اعداد محلی شود.
