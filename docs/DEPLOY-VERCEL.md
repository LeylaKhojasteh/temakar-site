# راه‌اندازی روی ورسل

این سند مرحله‌به‌مرحله می‌گوید چطور همین پروژه را روی ورسل بالا بیاوری. تنظیمات لازم از قبل در مخزن هست: `vercel.json`، `api/index.py` و `.vercelignore`.

## پیش‌نیازها

1. حساب ورسل.
2. یک پایگاه‌دادهٔ رایگان پستگرس (مثلاً Neon یا Supabase) و رشتهٔ اتصال آن.

## متغیرهای محیطی

این‌ها را در بخش تنظیمات پروژهٔ ورسل وارد کن:

| نام | مقدار نمونه | توضیح |
| --- | --- | --- |
| `DJANGO_SETTINGS_MODULE` | `config.settings.prod` | تنظیمات پروداکشن |
| `DJANGO_SECRET_KEY` | یک رشتهٔ تصادفی حداقل ۵۰ کاراکتری | کلید امنیتی |
| `DJANGO_ALLOWED_HOSTS` | `your-app.vercel.app` | دامنه‌های مجاز، با کاما جدا |
| `DJANGO_CSRF_TRUSTED_ORIGINS` | `https://your-app.vercel.app` | مبدأهای مورد اعتماد |
| `DATABASE_URL` | `postgres://user:pass@host/db?sslmode=require` | پایگاه‌داده |
| `WHITENOISE_USE_FINDERS` | `1` | سرو فایل‌های استاتیک بدون مرحلهٔ ساخت جدا |
| `DJANGO_SECURE_SSL_REDIRECT` | `1` | هدایت به نسخهٔ امن |
| `DJANGO_HSTS_SECONDS` | `31536000` | سیاست امنیتی مرورگر |

## مراحل

1. ابزار ورسل را نصب کن و وارد شو:

   ```bash
   npm i -g vercel
   vercel login
   ```

2. در ریشهٔ پروژه:

   ```bash
   vercel
   ```

   پاسخ پیش‌فرض‌ها را بپذیر؛ فایل `vercel.json` مسیرها را خودش تنظیم می‌کند.

3. متغیرهای محیطی بالا را در پیشخوان ورسل اضافه کن، سپس:

   ```bash
   vercel --prod
   ```

4. کاربر مدیر را یک بار از رایانهٔ خودت بساز (با همان `DATABASE_URL`):

   ```bash
   $env:DATABASE_URL="postgres://..."
   $env:DJANGO_SETTINGS_MODULE="config.settings.prod"
   $env:DJANGO_SECRET_KEY="<همان کلید>"
   $env:DJANGO_ALLOWED_HOSTS="your-app.vercel.app"
   python manage.py migrate
   python manage.py createsuperuser
   ```

5. پنل مدیریت: `https://your-app.vercel.app/manage/`

## محدودیت‌های مهم

- **فایل‌های آپلودی روی ورسل پایدار نیستند.** فایل‌سیستم تابع سرورلس موقتی است؛ تصاویری که در پنل آپلود می‌شوند ممکن است بعد از مدتی از دست بروند. برای استفادهٔ جدی، فضای ابری (مثل R2 یا S3) لازم است. برای نمایش، لوگوها و تصاویر ثابت در مخزن می‌مانند و مشکلی ندارند.
- تابع سرورلس بعد از بی‌کاری **سرد** می‌شود و اولین بازدید چند ثانیه طول می‌کشد.
- ایمیل واقعی تنظیم نشده است؛ پیام‌های فرم تماس فقط در پایگاه‌داده ذخیره می‌شوند و در پنل دیده می‌شوند.

## بررسی پس از انتشار

1. صفحهٔ اصلی و صفحه‌های فارسی و انگلیسی باز شوند.
2. فرم تماس یک پیام آزمایشی بفرستد.
3. ورود به `/manage/` و ذخیرهٔ تنظیمات.
4. تم تیره و تغییر زبان.
